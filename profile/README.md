## О нас

**Maniforge** — IT-компания, которая проектирует, разрабатывает и сопровождает цифровые продукты.

**Направления:**

- корпоративные сайты и лендинги
- миграция с хостинга на VPS
- DevOps: nginx, Docker, CI/CD
- автоматизация бизнес-процессов
