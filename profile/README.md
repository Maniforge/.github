## О нас

**Maniforge** — команда, которая проектирует, развивает и сопровождает цифровые продукты группы **Svitex** (ООО «Свит-Комплект» и связанные направления).

Мы занимаемся:

- корпоративными сайтами и лендингами
- внутренними сервисами и API
- миграцией с shared-хостинга на VPS
- DevOps: nginx, Docker, Caddy, CI/CD
